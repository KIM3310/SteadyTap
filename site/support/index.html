Support

Help for the public SteadyTap iOS and iPadOS app.

Start a session

  1. Select Start Calibration.
  2. Complete the tap targets and drag path.
  3. Review the generated profile.
  4. Complete the baseline and adaptive rounds.
  5. Review the comparison and local progress.

Haptics or layout

Open Preferences to toggle haptic feedback or change the challenge intensity. If a run feels uncomfortable or inaccurate, exit it and repeat calibration at a comfortable pace.

Delete app data

Select Clear Local Data in Preferences. This removes saved session summaries, settings, and any local test state. Removing the app also deletes its local container, subject to the user's Apple backup settings.

Contact

Use the private contact route for account-independent support or a privacy request. Use GitHub Issues only for non-sensitive software defects. Never post health information, credentials, or other sensitive personal data in a public issue.
