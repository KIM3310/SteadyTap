# App Review Notes

## Access

- No account or sign-in is required.
- No backend or external hardware is required.
- The App Store release performs no network upload.

## Review path

1. Launch SteadyTap.
2. Select **Start Calibration**.
3. Complete the tap targets and drag path.
4. Review the generated interaction profile and continue.
5. Complete the baseline round, followed by the adaptive round.
6. Review the score, accuracy, miss, timing, and weekly-goal comparison.
7. Return to the home screen to view local history.
8. Open **Preferences** to verify **Clear Local Data**, **Privacy Policy**, and **Support**.

## Purpose and data

SteadyTap is a touch-practice and interface-calibration utility. It is not a medical device and does not diagnose, monitor, prevent, or treat any condition. Practice history and settings are stored only on the device. The release build has no account, advertising, tracking, analytics, or cloud upload.
