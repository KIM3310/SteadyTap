# App Privacy Answers

Use these answers for version 1.0 only. Revisit them before any release that adds a network service, analytics, advertising, or an account.

| App Store Connect question | Version 1.0 answer |
| --- | --- |
| Does this app collect data? | No |
| Is data used to track users? | No |
| Does the app show third-party advertising? | No |
| Is an account required? | No |
| Is practice data transmitted off-device? | No |

SteadyTap stores calibration measurements, preferences, and recent session summaries locally. Users can remove that state with **Clear Local Data** or by uninstalling the app.
